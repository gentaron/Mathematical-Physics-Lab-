# Results homepage

The user wants a visible, extremely simple research homepage inspired by
Berkshire Hathaway: white background, serif typography, blue underlined links,
fine horizontal rules and no technology/dashboard aesthetic. Use plain HTML,
small inline CSS, no JavaScript, external fonts, framework, database or server
process. Responsive width and native details disclosure are sufficient.

Present verified findings with a short explanation of their significance and
next questions. Clearly separate reproduction, exact algebra and counterexamples
from unproved conjectures and new discoveries. All figures must come from the
existing run report. Do not invent AI activity or formal proofs.

Generate index.html alongside each research run, and provide a site export
command that copies one selected report and renders docs/index.html. It does
not execute a new experiment or overwrite the append-only research records.
docs/latest.json is the selected published snapshot. No timestamp claims of
live updates. Use existing public GitHub Pages branch publication from main/docs
with docs/.nojekyll; do not create another hosting service or custom domain.

Validate source-derived numbers, HTML escaping, output files, no runtime network
dependencies, desktop/mobile overflow and the native disclosure interaction.
Pages activation requires the repository's Settings/Pages publishing source;
the connected GitHub tools do not expose that administrative operation, so
provide its exact one-time setting after delivering the concrete homepage.
