# Mathematical Physics Lab Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** A free, reproducible Cosmohedron Explorer with exact checks and honest research records.

**Architecture:** Independent Python package; geometry and algebra feed a bounded
hypothesis evaluator and append-only ledger. CLI and GitHub Actions use that same
package. Optional localhost AI supplies structured proposals only.

**Tech Stack:** Python 3.12+, SymPy 1.14.0, pytest 8.4.2; optional Lean/mathlib and Ollama.

**Spec:** docs/superpowers/specs/2026-10-12-math-lab-design.md

## Global Constraints

- No required paid services, secrets, GPU, Mathematica, Aristotle or Clef.
- Matryoshka enumeration: 3–7 vertices; full Hasse diagram: at most 6.
- Finite agreement never becomes a universal or formal proof.
- No execution of candidate code or unrestricted symbolic parsing.
- CI uses public standard Ubuntu runners, job summaries, no cache or artifacts.

## Review Focus

- Invalid or oversized polygon requests fail before expensive computation.
- Root convention, empty face and reversed inclusion must agree with reference counts.
- Candidate payloads with unknown fields, huge rationals or executable strings are rejected.
- Identical experiments create distinct records; invalid records cannot claim formal proof.
- Optional AI failures and malformed CLI inputs return useful errors without paid fallbacks.
